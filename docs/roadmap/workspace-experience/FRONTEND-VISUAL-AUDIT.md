## Verification

- Isolated Chromium visual sweep: 3 viewport journeys passed, covering 8 captured states × light/dark × desktop/phone/reflow = 48 captures. Selected reviewed images above are retained, not every intermediate capture.
- Desktop: 1440×1000 CSS pixels. Phone: 390×844. Reflow equivalent: 720×500 CSS pixels with DPR2, representing the layout space of a 1440×1000 desktop at 200%. **This is not a physical-browser zoom or mobile keyboard test.**
- All 48 captured top-level viewports had `documentElement.scrollWidth <= innerWidth`; [raw measurements](evidence/frontend-visual-audit/viewport-metrics.json). This is a layout observation, not a guarantee that every possible imported title/media fits.
- Actual Shell agent capture submits only to the injected fictional agent. No live turn or message was sent. Preview reads/saves use only the publication fixture.
- Inbox change: 8 focused Chromium/WebKit journeys passed in `inbox-visibility.spec.ts`. Covers 1440/390/720 widths, both themes, initial row visibility, intentional collapse across awaited invalidation/refetch, open/back, normal priority defaults, search and audience change.
- Existing `inbox.spec.ts`: 22 Chromium/WebKit journeys passed in the preceding combined run. Six new-case failures in that first run were an incorrect fixture title selector (`Group discussion` vs actual `Planning group`); corrected focused rerun passed all8. No product failure was masked.
- Core typecheck and aggregate web fixture typecheck passed. React review: the fallback is derived from the existing nonempty tier list; only the existing state initializer consumes it, with no new effect, storage or request.
- New tests use the `window.prismInboxQuery` fixture export owned by the coordinated canonical-person slice. This change does not independently commit a second fixture seam.

Production/PWA/native installation, actual 200% browser zoom and physical phone keyboard/IME remain root release/device gates. The visual audit does not expand backend scope or mark those gates complete.
