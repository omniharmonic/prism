Support

Prism is free, open source software. You can get help in three places:

  • Setting up: follow the setup guide. The README covers installing on a Mac.
  • Something isn't working, or you have a question: open an issue on GitHub. Tell us which app and version you use (Settings → Advanced → About Prism), what you did, and what happened. Please leave out private notes or passwords.
  • A security problem: please don't post it publicly. Report it privately, as described in our security policy.

Common questions

The iPhone app asks for a server address. What do I enter?

Enter the https address of your Prism Server, the one you open in a browser. The app works only with a server you or someone you know runs. There is no Prism cloud.

How do I connect my phone quickly?

On your Mac, open Prism's setup checklist and choose "Pair a phone". Then scan the code with the iPhone camera.

How do I delete my account?

In the app, go to Settings → Account → Delete account. That removes your account from the server you signed in to. If you run the server yourself, everything on it is yours to delete.

Where is my data?

On your server, in a Parachute vault. Read the privacy page for details.
